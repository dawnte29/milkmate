# 🥛 밀크메이트

우유 배달 명단·동선·현관 비밀번호를 **한 화면에서** 보는 안드로이드용 웹앱(PWA).
아파트 → 동 → 라인 순서로 배달하고, 그날 갈 집만 골라서 보여줍니다.

- **아파트 → 동 → 라인 → 세대** 구조. 호수 끝 두 자리로 라인이 자동으로 나뉨 (1-2 / 3-4 / 5-6)
- 세대마다 **🔑 현관 비밀번호** 저장. 누르면 화면 가득 크게
- 우유 이름을 누르면 **사진**이 뜸
- 📦 **적재 수량**: 오늘 차에 실을 품목별 총 개수
- **월·수·금 명단을 각각 한 번만** 넣으면 그 뒤로는 안 쳐도 됨
- **배달 순서 · 품목 · 수량이 요일마다 따로** 저장됨
- 그날만 수량 ±, "오늘 쉼", "오늘만 추가" — 고정 명단은 안 건드림
- 인터넷 없이 동작

## 2. 명단 넣기

`📋 명단 붙여넣기` (첫 화면 또는 `⚙️ 설정`)

### 쓰는 형식

**아파트명 동-호수 이름 (비번) 품명 수량**

```
그린빌 101-201 박민수 (#0103 2468) 제주목초120 3
행복아파트 103-1501 홍길동 (#0101 1234) 제주착한900 1
행복아파트 106-701 배준호 (#0108#8642) 더밀크750 1
```

아파트 이름을 한 번만 쓰고 그 아래로 쭉 이어써도 됩니다. **타이핑이 제일 적은 방법:**

```
그린빌
101-201 박민수 (#0103 2468) 제주목초120 3
103-404 최지우 (#0106 3690) 상하유기750 1
행복아파트
101-1404 정다은 (#0105#9876) 연)세브450 2
```

> **아파트 이름을 꼭 넣으세요.** 안 넣으면 서로 다른 아파트의 같은 동 번호(101동 등)가 한 덩어리로 섞입니다.

### 알아서 처리되는 것

| 쓴 것 | 결과 |
|---|---|
| `103-1501` | 103동 1501호 → **1501호 = 1라인 → 1-2라인** |
| `(#0101 1234)` | 🔑 현관 비밀번호 |
| `(1304열쇠0000종)` | `#` 없이 한글이 섞여 있어도 통째로 비밀번호 |
| `(1304열쇠0000종 , 7시까지꼭투입)` | 콤마 앞은 🔑 비번, 뒤는 📝 메모 |
| `(문 앞에 두세요)` | 숫자가 없으면 전부 메모 |
| `월수금` `금` (**안 써도 됨**) | 배달 요일 |
| 없는 우유 이름 | **품목이 자동으로 만들어짐** |

사장님이 준 명단 원문을 그대로 붙여넣어도 대부분 읽습니다 (`순번`, `Page: 1`, 합계표 등은 알아서 버림).

### 월·수·금 딱 세 번만 ⭐

미리보기 화면에 **"이 명단은 무슨 요일 배달인가요?"** 가 있습니다.

| 언제 | 무엇을 | 결과 |
|---|---|---|
| 금요일 | 금요일 명단 (요일 `금`) | 그 집들이 **금** 배달로 저장 |
| 월요일 | 월요일 명단 (요일 `월`) + **✅ 합치기** | 금에도 있던 집 → **월·금** / 월에만 있는 집 → 새로 추가 |
| 수요일 | 수요일 명단 (요일 `수`) + **✅ 합치기** | **수** 가 더해짐 |

세 번 하면 전체 고객 명단이 완성됩니다. 그 뒤로는 그날그날 달라지는 것만 `조정` 으로 ±하면 됩니다.

| 버튼 | 언제 |
|---|---|
| **✅ 지금 명단에 합치기** | 평소. 이미 있는 세대는 품목 수량만 갱신 |
| **🔄 기존 명단 지우고 새로 넣기** | 처음부터 다시 짤 때. ⚠️ **요일 정보까지 전부 지워집니다** |

## 3. 요일마다 따로 저장되는 것 ⭐

`🏢 명단 관리` 맨 위에서 **`전체` / `월` / `수` / `금`** 을 고르면, 그 아래 모든 조작이 **고른 요일에만** 적용됩니다.

| 조작 | `월` 을 고른 상태 | `전체` 를 고른 상태 |
|---|---|---|
| ▲▼ 순서 바꾸기 | 월요일 순서만 | 모든 요일 공통 기본 순서 |
| 수량 ＋− | 월요일 수량만 (`↺ 기본값으로` 로 되돌림) | 모든 요일 공통 수량 |
| `＋ 품목 추가` | 월요일에만 들어감 | 모든 요일 |
| 품목 옆 `✕` | 월요일에서만 빠짐 | 모든 요일에서 삭제 |
| 세대·라인·동 삭제 | `🚫 월요일 배달에서 빼기` | `🗑 완전히 삭제` |

화면에 항상 **파란 글씨로 어느 쪽인지 표시**되니 헷갈리지 않습니다.
요일을 고르면 그날 배달이 없는 코스·동·라인은 목록에서 숨겨집니다.

## 4. 배달 순서 (동선)

명단을 처음 넣으면 **`아파트 → 동 번호 → 라인 번호 → 높은 층부터`** 로 자동 정렬됩니다.

- 실제 도는 순서가 다르면 `🏢 명단 관리`에서 **▲▼** 로 옮기세요. 한 번 옮기면 계속 기억합니다
- 라인은 **항상 2개씩** 묶임 (1-2 / 3-4 / 5-6). 되돌리려면 `⚙️ 설정 → 🚪 호수 기준으로 라인 다시 배정`
- 순서를 처음부터 다시 잡으려면 `⚙️ 설정 → 🔄 동선 자동 정렬` (⚠️ 요일별 순서도 함께 초기화)

같은 아파트에 같은 동 번호가 서로 다른 단지로 들어오면 단지 이름을 붙여 따로 보여줍니다. 같은 곳이면 동 이름을 똑같이 고치면 합쳐집니다.

## 5. 우유 품목

`🥛 우유 품목` 탭. 맨 위 검색칸과 정렬 칩은 **스크롤해도 고정**됩니다.

- **🔍 검색** — 우유 이름과 제조사 둘 다 검색됨
- **정렬** — `가나다` / `제조사` (제조사별로 묶어서 보여줌)
- **🏭 제조사** — 품목을 눌러 입력. 한 번 쓴 제조사는 자동완성에 뜸
- **📷 사진** — 폰에서 찍거나 갤러리에서 선택. 자동으로 용량을 줄여 저장 (한 장 50~200KB)

명단을 붙여넣으면 품목이 자동으로 만들어져 있으니 **사진과 제조사만 채워주면 끝**입니다.

## 6. 배달하는 날

1. `🚚 오늘 배달` — 오늘 요일에 해당하는 집만 순서대로
2. 명단과 다르면 세대의 **`조정`**
   - `＋ / −` 수량, `🚫 이 집 오늘 쉼`, `＋오늘만 추가`
   - **`↔ 다른 품목으로 교체`** — 대체 품목이 왔을 때. 없는 우유는 검색창에 이름을 치면 그 자리에서 새로 만들 수 있음
   - → **그날 하루만 적용되고 고정 명단은 그대로**
3. `📦 적재 수량` 으로 오늘 실을 총 개수 확인 후 차에 싣기
   - 배달한 품목은 **취소선**, 일부만 했으면 `남은개수 / 전체`
4. 배달하면서 **✓** 체크, 또는 `라인 배달 완료` (집이 2곳 이상인 라인에만)
5. 오른쪽 아래 **`📍 배달할 곳`** 이 지금 배달할 라인으로 데려다줍니다
6. **🔑 비밀번호를 누르면 화면 가득** 크게

전날 밤 미리 준비할 땐 헤더의 `›` 로 날짜를 넘기면 됩니다.

## 7. 백업 — 꼭 기억하세요

명단·사진은 **이 폰 안에만** 저장됩니다. 폰을 바꾸거나 크롬 데이터를 지우면 사라집니다.

- `⚙️ 설정 → 💾 백업 파일 내보내기` (사진 포함)
- 다운로드가 안 되면 `📋 전체 복사` → **카톡 "나에게 보내기"** 에 붙여넣기
- 복구는 `⚙️ 설정 → 📥 백업 불러오기`

> **주소가 바뀌면 데이터는 따라오지 않습니다.** 다른 주소로 옮길 때는 반드시 내보내기 → 불러오기.

## 9. PC에서 미리 확인하기

이 폴더에서 실행하면 `http://localhost:8765` 로 열립니다. (끄려면 Ctrl+C)

```bash
powershell -NoProfile -ExecutionPolicy Bypass -Command "$l=New-Object System.Net.HttpListener;$l.Prefixes.Add('http://localhost:8765/');$l.Start();Start-Process 'http://localhost:8765/';while($l.IsListening){$c=$l.GetContext();$p=Join-Path (Get-Location) ([Uri]::UnescapeDataString($c.Request.Url.AbsolutePath).TrimStart('/'));if($p -eq (Get-Location).Path){$p=Join-Path $p 'index.html'};if(Test-Path -LiteralPath $p -PathType Leaf){$b=[IO.File]::ReadAllBytes($p);$c.Response.OutputStream.Write($b,0,$b.Length)}else{$c.Response.StatusCode=404};$c.Response.Close()}"
```
